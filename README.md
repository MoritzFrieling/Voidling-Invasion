# Voidline Invasion

A dependency-free HTML5 Canvas arcade defense game. Pilot a combat ship through a large sector, stop enemy waves before they reach the Earth Gate, salvage resources for XP, and build a stronger ship between encounters.

## Run locally

Serve the `dist` directory with any static web server, then open `index.html` in a modern browser.

## Controls

- `WASD` — flight vector
- `Up Arrow` or left mouse — fire blaster
- `F` — charge and launch a heavy rocket
- `Q` — void boost
- `Shift` — precision flight
- `Escape` — pause

Progress and settings are stored locally in the browser.
